# Space-Shooter

A 2D arcade space shooter built with Unity and C#.

## Overview

Take control of a spaceship, fight enemy units, and survive in an arcade-style space combat experience.

## Features

- Spaceship movement
- Projectile shooting mechanics
- Enemy encounters
- Collision detection
- Score tracking

## Built With

- **Engine:** Unity
- **Language:** C#
- **Version Control:** Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Open the main scene and press **Play**.

## Project Structure

- `Assets/` — Game assets, scripts, and scenes
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration
